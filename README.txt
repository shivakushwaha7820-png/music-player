WAVE MUSIC PLAYER - TASK 4

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser (recommended: use VS Code Live Server).
4. Internet connection is required for the 10 demo tracks, which are streamed from SoundHelix.

FEATURES
- 10 demo tracks in the playlist
- Play / pause, next, previous
- Song title, artist and duration
- Progress bar with seeking
- Volume slider
- Playlist selection
- Shuffle and repeat
- Responsive design

Note: These are demo tracks, not popular commercial songs.
